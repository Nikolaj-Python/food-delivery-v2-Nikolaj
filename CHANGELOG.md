# Changelog

Все значимые изменения проекта FoodDelivery документируются в этом файле.

## [2.0.0] — 2026-11-03

### Added
- Полноценный MVP на Streamlit
- Меню с категориями и ценами
- Корзина с возможностью изменения количества
- Промокоды SAVE10 (10%) и WELCOME (15%)
- Оформление заказа (email + адрес)
- История заказов с деталями
- Программа лояльности: начисление 10% бонусов, возможность списания
- Сохранение данных в orders.json и bonus.json
- USER_GUIDE.md — руководство пользователя со скриншотами
- presentation/demo.md — презентация для заказчика
- RETROSPECTIVE.md — ретроспектива спринта
- Скриншоты основных экранов

### Fixed
- Корректный расчёт скидки и бонусов
- Сохранение состояния между перезапусками
- Очистка корзины после успешного заказа

### Known limitations
- Данные в JSON (нет БД)
- Нет мобильной версии
- Нет реальных платежей и уведомлений
